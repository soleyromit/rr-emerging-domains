## Context

Nursing penetration is far behind the existing PA/OT base (~50%) — Romit estimated
5-8%. The goal of this call was to define a standards-level competitive crosswalk,
starting with nursing, using the same visual format as an existing feature crosswalk
grid Wilson had already produced.

## The crosswalk grid ask (verbatim, cleaned)

> "The accreditation being able to go through all the standards and say, where do we
> meet versus the competitors meet? That would be a pretty darn phenomenal crosswalk
> grid. So similar to what we have in the feature crosswalk grid... but with each of
> the standards... not meeting it, partially meeting it, fully meeting it, or
> whatever."

Wilson confirmed feasibility ("I think that I can do it, that won't be a problem") and
named the specific standards to feed in: **ARC-PA, ACOTE, the AACN Essentials / CCNE
nursing standards, and ACEN**. Rows = standards, columns = competitors, cells = how
well each competitor's software meets each standard.

Romit connected this directly to work already in this repo: "basically what you've
kind of already done in the accreditation map that you have under the market, but take
it to [the next level]... from a representation point of view, yes, this will make a
lot of sense."

## Discipline-level feature-relevance grid (a second, separate ask)

Wilson raised a real gap: discipline-specific feature relevance isn't documented
anywhere. Verbatim: "How do I get access to really learn the feature sets of each
discipline? We don't have anything written down." Example given: timesheets as a
feature PTs would never use. Proposed shape: a never/sometimes/always grid, feature
rows × discipline columns. Action item: **check with Kanthi** for any existing
internal documentation of per-discipline feature usage before building this from
scratch.

## Two-tier accreditor structure (new finding, not previously captured in this repo)

Distinguishing accreditor *scope*, not just accreditor *name*:

- **Consortium**: the same program type (e.g. nursing) across multiple institutions —
  typically a state or regional grouping of same-discipline programs.
- **University**: one institution with many different programs bundled under shared
  university-level outcomes.
- **Regional**: verbatim — "there's only regional for education, teacher education,
  and there's not typically a regional accreditation for any other discipline."
- **State-level variation**: Pharmacy flagged as a likely exception — "different state
  has a different regulation" (per a separate conversation with Ruchi). Relevant to
  contracts and the skill-checklist product specifically.

Action item: **build this same accreditor-tier crosswalk for nursing first, then
education, social work, and counseling.**
